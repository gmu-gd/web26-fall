Exercise 2

Linking

Description

Make a new page in your E1 file or duplicate your E1 file. Link the frames of your e1 file together by adding some kind of navigation. How you link them together is up to you but the minimum is 1 should go to 2, 2 should go to 3, 3 should go to 4, 4 should go to the new 5th page and 5 should go back to 1. This is also a chance to update the design if you need to either to improve it or to adjust for the navigation elements.

Requirements

  • File is duplicated or a new page is created
  • Add an additional frame as number 5 that tells the typeface(s) and foundry(s) that designed it
  • Each frame from e1 linked to the next, with the last going back to the first
  • Link to a new working prototype on your class website

Final Submission

  • Turned in on time
  • All requirements met
  • Prototype link submitted on Canvas
  • Linked on your class index
