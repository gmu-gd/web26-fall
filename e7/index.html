Exercise 7

Typographic Hierarchy

Description

Choose a book from Project Gutenberg. Create three different layouts using the title, author, chapter(s), and a reasonable amount of text from the first chapter(s). Each layout should be unique and follow the rules below:

  • Layout 1: Only one typeface, no images, only two colors
  • Layout 2: Two typefaces, no images
  • Layout 3: Three typefaces, must use multiple images
  • The same typeface cannot be used on more than one layout

Requirements

  • All layouts use a different column structure
  • All elements are aligned to that column structure
  • Consistent header and footer on each page that allows me to navigate to the other layouts
  • Follows the layout rules above
  • Each layout includes the title, author, chapter(s), and text
  • 1440px wide by however tall it needs to be

Final Submission

  • Turned in on time
  • All requirements met
  • Prototype link submitted on Canvas
  • Linked on your class index
